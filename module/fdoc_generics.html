    fdoc_generics.f90

    modulefdoc_generics

    The overview of a generic interface: which ways there are to call it, and which types and ranks each one takes. Specific procedures with the same arguments make a call form, and each form gets a table with a row for each combination of types and a column for each rank. Types are compared as written, so two names of one kind count as different types. Pages are rendered in parallel, so nothing here calls a function returning a deferred-length string (see example/slen_race.f90).
