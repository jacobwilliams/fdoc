    fdoc_progress.f90

    modulefdoc_progress

    Progress in the terminal: a live bar for each stage of the run, leaving a line with its time, and warnings that do not get mixed up with the bar. When standard output is not a terminal there are no bars or colours, just a line for each stage.

    With --progress-lines there are lines for another program to read from standard output instead, each written at once. Warnings stay on standard error, and a run that fails has no [end] line.

    [ 42%] Parsing files 83/198
[done] Parsing files in 0.22 s
[end] 3456 pages written to ./doc in 2.31 s

    Stages run in parallel loops. Any thread can count, and only the first draws. Nothing here calls a function returning a deferred-length string (see example/slen_race.f90).
