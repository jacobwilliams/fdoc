    fdoc_stats.f90

    modulefdoc_stats

    The size of source files: how many lines hold code, comments or nothing. This uses fformat's tokens, so that a ! in a string is not taken for a comment. It runs in parallel, so nothing here calls a function returning a deferred-length string (see example/slen_race.f90).
