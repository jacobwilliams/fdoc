    fdoc_model.f90

    modulefdoc_model

    The documented program: source files and the entities in them.

    Entities live in one list and refer to each other by index. Each is held through an allocatable, so that growing the list or merging one list into another moves entities and does not copy them.

    Types

    attribute_t

    An attribute given in a statement of its own, such as public :: x, waiting to be applied.

    entity_box_t

    Holds an entity, so that it can be moved without being copied.

    entity_list_t

    A list of entities. Indices start at 1, and 0 means no entity.

    entity_more_t

    What only some entities have. Most entities are variables, which share one of these, so an entity takes half the memory; this makes up most of the memory used on large projects.

    entity_t

    A file, program unit, procedure, type, variable or the like. Which components apply depends on kind.
