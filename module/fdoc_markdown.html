    fdoc_markdown.f90

    modulefdoc_markdown

    Markdown to HTML, in the dialect of Python-Markdown with the extensions FORD uses: fenced code, tables, footnotes, definition lists, abbreviations, attribute lists, Markdown inside HTML, math, file inclusion, and FORD's links, aliases and admonitions.

    The block parser follows Python-Markdown: the text is split into chunks at blank lines, and a tree is built by processors tried in a fixed order, so that indentation and lists behave the same. Inline text is then read left to right.

    Documentation is rendered in parallel, so nothing here calls a function returning a deferred-length string (see example/slen_race.f90).
