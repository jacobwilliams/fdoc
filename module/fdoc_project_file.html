    fdoc_project_file.f90

    modulefdoc_project_file

    Reading settings from a project file, fpm.toml or a TOML string.

    A project file starts with Markdown metadata, optionally between --- lines: key: value lines, with values continued on lines indented by four or more blanks. Metadata ends at the first blank line, at an end marker, or at a line that fits neither form. The rest of the file is the text of the front page. An [extra.ford] table in fpm.toml next to the project file replaces its metadata, as in FORD; the text of the project file is then used whole. An [extra.fdoc] table does the same and comes first, and can give the front page: its text in front_page, or the Markdown file that holds it in front_page_file, relative to fpm.toml.

    subroutine load_project(path, directory, s, body, stat, errmsg)

    Read the settings and front page text of the project. Settings come from an [extra.fdoc] or [extra.ford] table in fpm.toml if there is one, and otherwise from the metadata of the project file. With no path the project file is ford.md, if it exists: [extra.fdoc] does not need one, as the text of the front page can be in its front_page, or the file named by front_page_file.
