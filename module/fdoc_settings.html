    fdoc_settings.f90

    modulefdoc_settings

    The project settings: FORD's options, their defaults and their conversion from text.

    Every source of settings (project file, fpm.toml, --config, command line) goes through set_option, which takes the option's values as a list of strings, the form the project file gives them.
