    fdoc.f90

    modulefdoc

    The fdoc program: documentation for modern Fortran, from FORD project files.

    A run goes through these stages in turn. Those that work on many files or pages at once use threads, and those that connect things across the whole project use one.

    graph LR
  A[Settings] --> B["Read files<br>(threads)"]
  B --> C["Parse<br>(threads)"]
  C --> D[Merge]
  D --> E[Link]
  E --> F["Markdown<br>(threads)"]
  F --> G["Graphs<br>(threads)"]
  G --> H["Pages<br>(threads)"]
