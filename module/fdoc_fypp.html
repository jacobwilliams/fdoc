    fdoc_fypp.f90

    modulefdoc_fypp

    A port to Fortran of the parts of Fypp, the preprocessor by Balint Aradi, that the Fortran standard library needs, so that fdoc can read Fypp sources without running Python.

    Fypp's directives hold Python expressions. A small evaluator here covers the ones in use: literals, lists, tuples, comprehensions, f-strings, slices, conditional expressions, and the functions and string methods listed in call_builtin and call_method. Anything else stops with an error that names it, and is left for later, as are the directives del, global, stop, nextarg and contains, direct calls with @: and @{...}@, and line numbering.

    All state is in a fypp_t made for each file, so that files can be processed in parallel. As in the rest of fdoc, no function returns a deferred-length string (see example/slen_race.f90).
